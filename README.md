# 대학·진로교육 인식 가상 설문 (Nemotron-Personas-Korea)

NVIDIA의 한국인 합성 페르소나 100만 명([nvidia/Nemotron-Personas-Korea](https://huggingface.co/datasets/nvidia/Nemotron-Personas-Korea), CC-BY-4.0)에서
원하는 인구집단을 골라, 대학교육과 진로교육에 대한 가치관·태도·의견을 **리커트 5점 척도**로 묻는 가상 설문을 돌리고
결과를 바로 통계 처리합니다.

> 합성 페르소나의 응답은 실제 여론이 아닙니다. 설문지 사전 점검(파일럿), 문항 개선, 가설 탐색에 쓰고
> 결론은 실제 조사로 확인하세요.

## 웹 대시보드로 쓰기 (Streamlit Community Cloud, 무료)

설치 없이 `https://<이름>.streamlit.app` 주소로 접속해 쓰는 방법입니다. 처음 한 번만 연결하면 이후 저장소에 올린 변경이 자동 반영됩니다.

1. https://share.streamlit.io 에 GitHub 계정으로 로그인합니다.
2. **Create app → Deploy a public app from GitHub**를 고릅니다.
3. Repository `2023swhs3rd-a11y/nemotron-survey`, Branch `main`, Main file path `app.py`를 입력합니다.
4. App URL에 원하는 주소(예: `nemotron-survey`)를 적고, Advanced settings에서 Python 3.12를 고른 뒤 **Deploy**를 누릅니다.

처음 접속하면 Hugging Face에서 100만 명의 인구통계 열만 읽어 오느라 1~2분 걸립니다(텍스트 열은 받지 않음).

## 응답 방식

- **생활서사 코드북 추정 (기본)**: 아래 "방법"처럼 페르소나 문장의 교육·진로 단서로 응답을 추정합니다. API 비용이 들지 않습니다.
- **데모**: 규칙 기반 임의 응답으로 화면과 통계 흐름을 확인합니다. 수치에 의미는 없습니다.
- **응답 파일 업로드**: 표본을 뽑은 뒤 응답 양식(엑셀/CSV)을 내려받아 문항별 1~5점을 채워 올리면 바로 통계를 냅니다.
- **Claude** (선택): 환경변수나 Streamlit Secrets에 `ANTHROPIC_API_KEY`가 있거나 `ENABLE_CLAUDE = "1"`이면 나타납니다.
  Claude가 각 페르소나가 되어 응답합니다. API 사용료는 Claude Pro 구독과 별도로 Console에서 결제합니다.

## 방법: 생활서사 코드북 추정

유승철·임승희(2026, 광고연구 149호)가 Nemotron-Personas-Korea의 생활서사 텍스트를 코드북으로 0~2점 점수화해
식품·관광·건강 단서를 분석한 절차를 대학·진로교육 설문에 맞게 옮겼습니다.

1. **텍스트 통합**: 페르소나의 요약·직업·가족·성장 배경·커리어 목표·역량·취미 문장을 하나로 합칩니다.
2. **코드북 점수화**: 단서 6개(학업 관여, 커리어 성장, 평생학습, 실무·현장 지향, 자녀교육 관심, 경제적 부담)마다
   키워드를 찾아 0점(없음), 1점(키워드 1개, 약한 단서), 2점(서로 다른 키워드 2개 이상, 반복·구체적 단서)을 줍니다.
   코드북은 `survey/codebook.json`에 있습니다.
3. **응답 추정**: 문항별로 `기준점 + Σ(가중치 × 단서 점수) + Σ(가중치 × 인구통계 항) + 무작위 오차`를 1~5로 반올림합니다.
   인구통계 항은 4년제 대학 이상, 35세 미만, 60세 이상입니다. 가중치는 연구자가 정한 가설이며 앱 4단계에서 고칠 수 있습니다.
   같은 사람·같은 설정이면 항상 같은 응답이 나옵니다.
4. **분석**: 문항 통계와 함께 단서별 0·1·2점 분포, 단서 간 차이(Friedman 검정), 집단별 단서 차이(t검정·분산분석과 비모수 검정, 효과크기)를 냅니다.
   논문과 같이 큰 표본에서는 p값보다 효과크기를 함께 해석하세요.

**해석 원칙**: 추정 응답은 실제 의견의 예측값이 아니라, 합성 페르소나의 생활 맥락에서 "이런 집단은 이런 태도를 보일 수 있다"는
가설을 세우는 도구입니다. 결과는 가중치(연구자의 가정)에 직접 좌우되므로, 결론은 실제 조사로 확인해야 합니다.
키워드 방식은 문맥을 완전히 읽지 못하는 한계가 있습니다(논문은 GPT-4로 맥락을 함께 판단했습니다).

## 흐름

1. **대상 선택**: 나이, 성별, 시도·시군구, 학력, 전공 계열, 혼인 상태, 주거 형태, 가구 유형, 직업 키워드로 인구집단을 고릅니다.
2. **표본 크기**: 신뢰수준과 허용 오차로 최소 표본을 계산하고(Cochran 공식, 유한모집단 보정),
   집단 비교를 계획하면 검정력 분석(효과크기 d, 검정력 80%)으로 집단당 필요 인원을 더해 권장 표본을 냅니다.
   예) 모집단이 크면 95% 신뢰수준·±5% 오차에서 384명, 3개 연령대를 d=0.3으로 비교하면 525명.
3. **층화 추출**: 성별·연령대·시도 등 층별 모집단 비율을 그대로 유지해 뽑습니다.
4. **응답 만들기**: 위 응답 방식 중 하나로 응답을 만듭니다. Claude 방식에서는 Claude가 각 페르소나(인구통계 + 직업·가족·성장 배경·커리어 목표 서술)가 되어 문항마다 1~5점으로 답합니다.
   JSON 스키마로 출력을 강제해 응답이 항상 1~5 정수로 들어옵니다.
5. **통계**: 문항별 평균·표준편차·95% 신뢰구간·응답 분포·긍정/부정 비율, 영역별 척도 점수와 Cronbach α,
   집단 비교(두 집단 Welch t·Mann-Whitney, 세 집단 이상 일원분산분석·Kruskal-Wallis, 효과크기 d·η²).
   엑셀 보고서와 원자료 CSV로 내려받을 수 있습니다.

| 번호 | 영역 | 문항 |
|---|---|---|
| Q01 | 대학교육 가치 | 대학 교육은 개인의 사회적·경제적 성공에 꼭 필요하다. |
| Q02 | 대학교육 가치 | 현재 등록금 수준을 고려할 때 대학 교육은 그만한 가치가 있다. |
| Q03 | 대학교육 가치 | 대학 교육은 실제 직업 세계에서 필요한 역량을 잘 길러 준다. |
| Q04 | 대학교육 가치 (역문항) | 대학 진학보다 조기 취업이나 직업교육이 더 나은 선택일 수 있다. |

| Q08 | 진로교육 효과 | 대학은 재학생에게 충분한 진로·취업 지원을 제공하고 있다. |
| Q09 | 진로교육 효과 | 성인도 평생교육을 통해 진로를 다시 설계할 기회가 충분하다. |

척도: 1 전혀 그렇지 않다 · 2 그렇지 않다 · 3 보통이다 · 4 그렇다 · 5 매우 그렇다.

모든 사용자에게 기본으로 보이게 하려면 내려받은 `custom_questions.json`을 저장소 최상위에 올리세요. 기본 문항은 `survey/questions.json`에서 고칩니다.

## 설치와 실행

Python 3.10 이상이 필요합니다(Claude Python SDK 1.x 요구 사항). 버전은 `python3 --version`으로 확인하세요.

```bash
pip install -r requirements.txt
streamlit run app.py
```

Claude API 키는 앱 사이드바의 입력칸에 넣거나, 실행 전에 `export ANTHROPIC_API_KEY=sk-ant-...`로 지정합니다.
키는 [Claude Console](https://console.anthropic.com)의 API Keys에서 발급합니다.

데이터는 Hugging Face에서 필요한 열만 바로 읽습니다. parquet 파일을 받아 둔 폴더가 있으면 `NEMOTRON_DATA_DIR=/경로`로 지정하세요.

API 키 없이 화면과 통계 흐름만 보려면 사이드바에서 **데모** 모드를 고르세요(규칙 기반 임의 응답이라 수치에 의미는 없습니다).
데이터 없이 시험하려면 가짜 데이터를 만들어 쓸 수 있습니다.

```bash
python tests/make_mock_data.py mock_data 20000
NEMOTRON_DATA_DIR=mock_data streamlit run app.py
```

### 명령줄 실행

```bash
# 서울·경기 19~29세, 성별·연령대 비교, 표본 수 자동 계산
python cli.py --age 19 29 --province 서울 경기 --compare sex age_group
```

`outputs/`에 엑셀 보고서가 저장됩니다. `python cli.py -h`로 모든 옵션을 볼 수 있습니다.

## 모델과 비용

기본 모델은 `claude-opus-5-5`(effort `low`)이고, 사이드바에서 `claude-sonnet-5-5`, `claude-haiku-5-5`로 바꿀 수 있습니다.
응답자 1명당 API 요청 1번이라 400명이면 400번 요청합니다. 큰 표본은 Haiku로 먼저 시험해 보세요.
Opus·Sonnet에서는 안전 분류기가 요청을 거절하면 서버가 다른 모델로 대신 응답하도록(`fallbacks: "default"`) 켜 두었습니다.

## 주의할 점

- 데이터의 성별·학력·직업 등은 서로 독립적으로 생성되어 실제 변수 간 상관관계가 완전히 반영되지 않습니다.
- 19세 미만은 데이터에 없습니다(중·고등학생 대상 조사는 불가).
- LLM 응답은 고정관념을 증폭하거나 중간값으로 몰릴 수 있습니다. 응답 이유(comment)를 함께 살펴보세요.
