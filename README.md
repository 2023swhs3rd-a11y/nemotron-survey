# 대학·진로교육 인식 가상 설문 (Nemotron-Personas-Korea)

NVIDIA의 한국인 합성 페르소나 100만 명([nvidia/Nemotron-Personas-Korea](https://huggingface.co/datasets/nvidia/Nemotron-Personas-Korea), CC-BY-4.0)에서
원하는 인구집단을 골라, 대학교육과 진로교육에 대한 가치관·태도·의견을 묻는 **리커트 5점 척도 설문**을 가상으로 실시하고
결과를 바로 통계 처리하는 웹 대시보드입니다.

- 웹 주소: https://nemotron-survey-korea.streamlit.app
- 설치 없이 브라우저에서 바로 쓸 수 있고, 이 저장소의 `main` 브랜치에 올린 변경이 자동으로 반영됩니다.

> **해석 원칙**: 합성 페르소나의 가상 응답은 실제 여론이 아닙니다. 설문지 사전 점검, 문항 개선, 집단 간 차이에 대한
> 가설 탐색에 쓰고, 결론은 실제 조사로 확인하세요.

## 사용 순서

| 단계 | 화면 | 하는 일 |
|---|---|---|
| 1 | 조사 대상 인구집단 | 나이, 성별, 시도·시군구, 학력, 전공 계열, 혼인 상태, 주거 형태, 가구 유형, 직업 키워드로 모집단을 고릅니다. |
| 2 | 표본 크기와 추출 | 신뢰수준·허용 오차·집단 비교 계획으로 권장 표본 수를 계산하고, 성별·연령대·시도 비율을 유지해 층화 추출합니다. |
| 3 | 설문 문항 | 추천 문항 10개를 고르거나 끄고, 문항을 추가합니다. |
| 4 | 응답 만들기 | 사이드바에서 고른 응답 방식으로 응답을 만듭니다. |
| 5 | 통계 결과 | 문항·영역 통계, 집단 비교, 생활서사 단서 분석을 보고 엑셀·CSV로 내려받습니다. |

## 응답 방식 (사이드바)

| 방식 | 설명 | 용도 |
|---|---|---|
| **생활서사 코드북 추정** (기본) | 페르소나 문장의 교육·진로 단서와 학력·연령으로 응답을 추정합니다. 아래 "방법" 참고. | 가설 탐색 |
| **응답 파일 업로드** | 표본별 응답 양식(엑셀/CSV)을 내려받아 1–5점을 채워 올리면 바로 통계를 냅니다. | 실제 응답 분석 |
| **데모** | 학력·나이에 따른 고정 규칙과 무작위 값으로 만든 임의 응답입니다. | 화면·통계 흐름 점검 |
| **Claude** (숨김) | Claude가 각 페르소나가 되어 응답합니다. `ANTHROPIC_API_KEY` 또는 `ENABLE_CLAUDE = "1"`을 Streamlit Secrets나 환경변수에 넣으면 나타납니다. API 사용료는 Claude Pro 구독과 별도입니다. | 가설 탐색 |

## 방법: 생활서사 코드북 추정

유승철·임승희(2026), 「소비자 합성 페르소나 데이터를 활용한 생활서사 기반 광고 전략 탐색」(광고연구 149호)이
같은 데이터의 생활서사 텍스트를 코드북으로 0–2점 점수화한 절차를 대학·진로교육 설문에 맞게 옮겼습니다.

1. **텍스트 통합**: 페르소나의 요약, 직업, 가족, 성장 배경, 커리어 목표, 역량, 취미 문장을 하나로 합칩니다.
2. **단서 점수화**: 단서 6개마다 코드북 키워드를 찾아 0점(없음), 1점(키워드 1개, 약한 단서),
   2점(서로 다른 키워드 2개 이상, 반복·구체적 단서)을 줍니다.

   | 단서 | 예시 키워드 |
   |---|---|
   | 학업 관여 | 대학, 전공, 공부, 연구, 학위 |
   | 커리어 성장 | 승진, 이직, 경력, 자격증, 창업 |
   | 평생학습 | 배우고, 강좌, 수강, 문화센터, 새로운 기술 |
   | 실무·현장 지향 | 현장, 손재주, 숙련, 장사, 농사 |
   | 자녀교육 관심 | 자녀, 손주, 학원, 입시, 교육비 |
   | 경제적 부담 | 생활비, 대출, 절약, 등록금, 비용 |

3. **응답 추정**: 문항마다 `기준점(3) + Σ(가중치 × 단서 점수) + Σ(가중치 × 인구통계 항) + 무작위 오차`를 1–5로 반올림합니다.
   인구통계 항은 4년제 대학 이상(`edu_high`), 35세 미만(`young`), 60세 이상(`old`)이며 해당하면 1입니다.
   예) Q01에서 학업 관여 2점인 4년제 대졸자: 3 + 0.5×2 + 0.4 = 4.4 → 대체로 4점.
   같은 사람·같은 설정이면 항상 같은 응답이 나옵니다.
4. **가중치 편집**: 기본 가중치는 연구자 가설의 초안입니다. 앱 4단계 "추정 규칙" 표에서 바로 고칠 수 있고,
   기본값은 `survey/codebook.json`의 `weights`에서 바꿉니다. 추가한 문항은 가중치 0으로 시작합니다.

**한계**: 결과는 가중치(연구자의 가정)에 직접 좌우됩니다. 키워드 방식은 문맥을 완전히 읽지 못합니다(논문은 GPT-4로 맥락을 함께 판단).
데이터의 인구통계 변수는 서로 독립적으로 생성되어 실제 상관관계가 완전히 반영되지 않았고, 19세 미만은 없습니다.

## 추천 문항 10개

| 번호 | 영역 | 문항 |
|---|---|---|
| Q01 | 대학교육 가치 | 대학 교육은 개인의 사회적·경제적 성공에 꼭 필요하다. |
| Q02 | 대학교육 가치 | 현재 등록금 수준을 고려할 때 대학 교육은 그만한 가치가 있다. |
| Q03 | 대학교육 가치 | 대학 교육은 실제 직업 세계에서 필요한 역량을 잘 길러 준다. |
| Q04 | 대학교육 가치 (역문항) | 대학 진학보다 조기 취업이나 직업교육이 더 나은 선택일 수 있다. |
| Q05 | 교육 개선 요구 | 한국 사회에서는 대학 졸업장(학벌)이 지나치게 중요하게 여겨진다. |
| Q06 | 진로교육 효과 | 중·고등학교의 진로교육은 학생의 진로 결정에 실질적인 도움이 된다. |
| Q07 | 교육 개선 요구 | 진로교육은 대학 입시보다 학생 개인의 적성과 흥미를 우선해야 한다. |
| Q08 | 진로교육 효과 | 대학은 재학생에게 충분한 진로·취업 지원을 제공하고 있다. |
| Q09 | 진로교육 효과 | 성인도 평생교육을 통해 진로를 다시 설계할 기회가 충분하다. |
| Q10 | 교육 개선 요구 | 정부는 대학교육과 진로교육에 대한 공적 투자를 늘려야 한다. |

척도: 1 전혀 그렇지 않다 · 2 그렇지 않다 · 3 보통이다 · 4 그렇다 · 5 매우 그렇다. 역문항(Q04)은 영역 점수를 낼 때 6−점수로 바꿉니다.

**문항 추가**: 3단계 "문항 추가하기"에서 넣습니다. 추가 문항은 브라우저 세션 동안 유지되며 JSON으로 내려받았다가 다시 불러올 수 있습니다.
모든 사용자에게 기본으로 보이게 하려면 내려받은 `custom_questions.json`을 저장소 최상위에 올리세요. 기본 문항은 `survey/questions.json`에서 고칩니다.

## 통계 처리

- **표본 크기**: Cochran 공식(유한모집단 보정, p=0.5). 예) 모집단이 크면 95%·±5%에서 384명.
  집단 비교를 계획하면 검정력 분석(효과크기 d, 검정력 80%)으로 집단당 인원을 더합니다. 예) 3개 연령대, d=0.3이면 525명.
- **문항 통계**: 응답 수, 평균, 표준편차, 95% 신뢰구간, 1–5점 분포, 긍정(4+5)·부정(1+2) 비율, 응답 분포 막대그래프.
- **영역 통계**: 역문항을 바꾼 영역 평균과 Cronbach α.
- **집단 비교**: 두 집단은 Welch t검정과 Mann-Whitney, 세 집단 이상은 일원분산분석과 Kruskal-Wallis, 효과크기 Cohen d·η². 5명 미만 집단은 제외.
- **생활서사 단서 분석** (코드북 방식): 단서별 평균과 0·1·2점 분포, 단서 간 차이(Friedman 검정), 집단별 단서 차이.
  표본이 크면 작은 차이도 유의하므로 효과크기를 함께 해석하세요.
- **내보내기**: 설정·응답자 구성·문항/영역 통계·집단 비교·단서 분석·원자료를 담은 엑셀 보고서와 원자료 CSV.

## 데이터 읽는 방식

- 100만 명의 인구통계 열만 Hugging Face의 parquet 변환본(`refs/convert/parquet`)에서 범위 요청으로 읽습니다(전체 약 2GB를 받지 않음). 첫 접속 때 1~2분 걸립니다.
- 페르소나 문장은 필요할 때만(코드북 추정, 미리 보기, Claude) Hugging Face datasets-server API로 표본 인원만 가져옵니다.
  가져오지 못한 사람은 인구통계만으로 추정하고 화면에 그 수를 알려 줍니다.
- parquet 파일을 받아 둔 폴더가 있으면 `NEMOTRON_DATA_DIR=/경로`로 로컬 파일을 씁니다.

## 배포 (Streamlit Community Cloud)

1. https://share.streamlit.io 에 GitHub 계정으로 로그인합니다.
2. **Create app → Deploy a public app from GitHub**에서 Repository `2023swhs3rd-a11y/nemotron-survey`, Branch `main`, Main file path `app.py`를 입력합니다.
3. Advanced settings에서 Python 3.12를 고르고 **Deploy**를 누릅니다. Claude 방식을 쓰려면 같은 곳의 Secrets에 `ANTHROPIC_API_KEY = "sk-ant-..."`를 넣습니다.

## 내 컴퓨터에서 실행

Python 3.10 이상(3.12~3.13 권장)이 필요합니다.

```bash
git clone https://github.com/2023swhs3rd-a11y/nemotron-survey
cd nemotron-survey
python3 -m pip install -r requirements.txt
python3 -m streamlit run app.py
```

명령줄로 한 번에 실행하고 `outputs/`에 엑셀 보고서를 저장할 수도 있습니다.

```bash
# 서울·경기 19~29세, 성별·연령대 비교, 생활서사 코드북 추정(기본), 표본 수 자동 계산
python3 cli.py --age 19 29 --province 서울 경기 --compare sex age_group
```

`--mode`는 `codebook`(기본), `demo`, `llm` 중에서 고릅니다. `python3 cli.py -h`로 모든 옵션을 볼 수 있습니다.
데이터 없이 시험하려면 가짜 데이터를 만들어 `NEMOTRON_DATA_DIR`로 지정합니다.

```bash
python3 tests/make_mock_data.py mock_data 20000
NEMOTRON_DATA_DIR=mock_data python3 -m streamlit run app.py
```
