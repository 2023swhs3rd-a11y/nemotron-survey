# 대학·진로교육 인식 가상 설문 (Nemotron-Personas-Korea)

NVIDIA의 한국인 합성 페르소나 100만 명([nvidia/Nemotron-Personas-Korea](https://huggingface.co/datasets/nvidia/Nemotron-Personas-Korea), CC-BY-4.0)에서
원하는 인구집단을 골라, 대학교육과 진로교육에 대한 가치관·태도·의견을 **리커트 5점 척도**로 묻는 가상 설문을 돌리고
결과를 바로 통계 처리합니다.

> 합성 페르소나의 응답은 실제 여론이 아닙니다. 설문지 사전 점검(파일럿), 문항 개선, 가설 탐색에 쓰고
> 결론은 실제 조사로 확인하세요.

## 흐름

1. **대상 선택**: 나이, 성별, 시도·시군구, 학력, 전공 계열, 혼인 상태, 주거 형태, 가구 유형, 직업 키워드로 인구집단을 고릅니다.
2. **표본 크기**: 신뢰수준과 허용 오차로 최소 표본을 계산하고(Cochran 공식, 유한모집단 보정),
   집단 비교를 계획하면 검정력 분석(효과크기 d, 검정력 80%)으로 집단당 필요 인원을 더해 권장 표본을 냅니다.
   예) 모집단이 크면 95% 신뢰수준·±5% 오차에서 384명, 3개 연령대를 d=0.3으로 비교하면 525명.
3. **층화 추출**: 성별·연령대·시도 등 층별 모집단 비율을 그대로 유지해 뽑습니다.
4. **응답 생성**: Claude가 각 페르소나(인구통계 + 직업·가족·성장 배경·커리어 목표 서술)가 되어 문항마다 1~5점으로 답합니다.
   JSON 스키마로 출력을 강제해 응답이 항상 1~5 정수로 들어옵니다.
5. **통계**: 문항별 평균·표준편차·95% 신뢰구간·응답 분포·긍정/부정 비율, 영역별 척도 점수와 Cronbach α,
   집단 비교(두 집단 Welch t·Mann-Whitney, 세 집단 이상 일원분산분석·Kruskal-Wallis, 효과크기 d·η²).
   엑셀 보고서와 원자료 CSV로 내려받을 수 있습니다.

## 추천 문항 10개

| 번호 | 영역 | 문항 |
|---|---|---|
| Q01 | 대학교육 가치 | 대학 교육은 개인의 사회적·경제적 성공에 꼭 필요하다. |
| Q02 | 대학교육 가치 | 현재 등록금 수준을 고려할 때 대학 교육은 그만한 가치가 있다. |
| Q03 | 대학교육 가치 | 대학 교육은 실제 직업 세계에서 필요한 역량을 잘 길러 준다. |
| Q04 | 대학교육 가치 (역문항) | 대학 진학보다 조기 취업이나 직업교육이 더 나은 선택일 수 있다. |
| Q05 | 교육 개선 요구 | 한국 사회에서는 대학 졸업장(학벌)이 지나치게 중요하게 여겨진다. |
| Q06 | 진로교육 효과 | 중·고등학교의 진로교육은 학생의 진로 결정에 실질적인 도움이 된다. |
| Q07 | 교육 개선 요구 | 진로교육은 대학 입시보다 학생 개인의 적성과 흥미를 우선해야 한다. |
| Q08 | 진로교육 효과 | 대학은 재학생에게 충분한 진로·취업 지원을 제공하고 있다. |
| Q09 | 진로교육 효과 | 성인도 평생교육을 통해 진로를 다시 설계할 기회가 충분하다. |
| Q10 | 교육 개선 요구 | 정부는 대학교육과 진로교육에 대한 공적 투자를 늘려야 한다. |

척도: 1 전혀 그렇지 않다 · 2 그렇지 않다 · 3 보통이다 · 4 그렇다 · 5 매우 그렇다.
역문항(Q04)은 영역 점수를 낼 때 6−점수로 바꿉니다.

**문항 추가**: 앱의 3단계 "문항 추가하기"에서 넣으면 `custom_questions.json`에 저장되어 다음 실행에도 남습니다.
기본 문항은 `survey/questions.json`에서 직접 고칠 수 있습니다.

## 설치와 실행

```bash
pip install -r requirements.txt
export ANTHROPIC_API_KEY=sk-ant-...      # Claude 응답 모드에 필요
streamlit run app.py
```

처음 실행하면 Hugging Face에서 데이터(parquet)를 내려받아 캐시합니다. 이미 받아 둔 폴더가 있으면
`NEMOTRON_DATA_DIR=/경로`로 지정하세요.

API 키 없이 화면과 통계 흐름만 보려면 사이드바에서 **데모** 모드를 고르세요(규칙 기반 임의 응답이라 수치에 의미는 없습니다).
데이터 없이 시험하려면 가짜 데이터를 만들어 쓸 수 있습니다.

```bash
python tests/make_mock_data.py mock_data 20000
NEMOTRON_DATA_DIR=mock_data streamlit run app.py
```

### 명령줄 실행

```bash
# 서울·경기 19~29세, 성별·연령대 비교, 표본 수 자동 계산
python cli.py --age 19 29 --province 서울 경기 --compare sex age_group
```

`outputs/`에 엑셀 보고서가 저장됩니다. `python cli.py -h`로 모든 옵션을 볼 수 있습니다.

## 모델과 비용

기본 모델은 `claude-opus-5-5`(effort `low`)이고, 사이드바에서 `claude-sonnet-5-5`, `claude-haiku-5-5`로 바꿀 수 있습니다.
응답자 1명당 API 요청 1번이라 400명이면 400번 요청합니다. 큰 표본은 Haiku로 먼저 시험해 보세요.
Opus·Sonnet에서는 안전 분류기가 요청을 거절하면 서버가 다른 모델로 대신 응답하도록(`fallbacks: "default"`) 켜 두었습니다.

## 주의할 점

- 데이터의 성별·학력·직업 등은 서로 독립적으로 생성되어 실제 변수 간 상관관계가 완전히 반영되지 않습니다.
- 19세 미만은 데이터에 없습니다(중·고등학생 대상 조사는 불가).
- LLM 응답은 고정관념을 증폭하거나 중간값으로 몰릴 수 있습니다. 응답 이유(comment)를 함께 살펴보세요.
